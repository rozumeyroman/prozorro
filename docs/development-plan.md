# План розробки MCP-сервера Prozorro

Мета: Claude через MCP-сервер знаходить закупівлі з нашими товарами, показує переможців і ціни, аналізує технічні завдання.
Деталі API наведено в `docs/research/prozorro-api.md`, специфікації лежать у `api-specs/`.

Стек: Python, MCP Python SDK, httpx, SQLite (з повнотекстовим пошуком FTS5), openpyxl.

Позначки: ✅ виконано · ◐ частково · ⬜ не почато.

---

## Етап 0. Каркас проєкту ✅

**Результат:** сервер підключається до Claude. Інструмент `status` показує, що сервер працює і бачить API Prozorro.

- ✅ Структура Python-проєкту (`src/prozorro_mcp`, `pyproject.toml`, uv), налаштування через змінні середовища.
- ✅ Тести (41) і лінтер (ruff); тести працюють без мережі на імітації API Prozorro, побудованій на реальному тендері з документації Prozorro.
- ✅ Наскрізний тест: справжній MCP-клієнт запускає сервер через stdio.
- ✅ MCP-сервер (MCP SDK 2.x) та інструмент `status`.
- ✅ Інструкція з підключення до Claude Desktop і `.mcp.json` для Claude Code (`README.md`).

## Етап 1. Аналіз конкретного тендера ◐

**Результат за планом:** дати Claude тендер і запитати про учасників і переможця, прочитати ТЗ, дізнатися ринкову ціну, підібрати коди CPV.

- ✅ Клієнт ЦБД API з повторами на 429 і збої мережі.
- ✅ `get_tender`: замовник, лоти, позиції (CPV), пропозиції учасників з цінами за одиницю, переможці, знижка, договори, документи.
- ✅ `list_documents`: документи тендера (остання версія кожного).
- ✅ Підбір кодів CPV зроблено як дослідження: `docs/cpv-codes.md` за офіційним довідником ДК 021.
- ⬜ **`read_document`**: текст з PDF, DOCX, XLSX, підписаних `.p7s` та архівів; для сканів розпізнавання тексту (OCR). **Найважливіший відкладений пункт:** від нього залежать «що саме виграло» та аналіз ТЗ.
- ⬜ `get_contract`: повний договір, характеристики позицій, зміни після підписання.
- ⬜ Catalog API: `catalog_search`, `catalog_prices` (ринкові ціни Prozorro Market), визначення моделі за посиланням на товар у пропозиції.
- ⬜ `cpv_lookup` як інструмент (розшифровка і пошук кодів у розмові).

## Етап 2. Синхронізація та пошук закупівель ◐

**Результат за планом:** «знайди всі закупівлі моїх товарів за пів року», «покажи завершені тендери на товар X у Львівській області», дані актуальні з затримкою в кілька хвилин.

- ✅ Синхронізатор стрічки тендерів з тришаровим фільтром: попередній відсів за стрічкою, тема за кодами CPV і ключовими словами, вартість релевантних лотів (`docs/tender-filter.md`).
- ✅ Кеш рішень фільтра: кожен тендер завантажується один раз, зміни нецікавих тендерів пропускаються.
- ✅ База SQLite з повнотекстовим пошуком.
- ✅ `sync_tenders` за період (`today`, `7d`, дата), нові або також змінені тендери (`only_new`); статистика відсіювання за шарами.
- ✅ `search_tenders`: текст, тема, мінімальна вартість, дати, статус, сортування, сторінки.
- ✅ `get_tender` за номером `UA-…` або посиланням (для тендерів у локальній базі).
- ✅ Перший прогін на живих даних (5–6 жовтня): ~11 тис. змін за день, ~750 повних завантажень, ~50 с.
- ◐ Калібрування фільтра: за живими даними додано виключення комплектуючих і кабелів, але фільтр `cybersecurity` на живих даних ще не перевіряли.
- ⬜ **Інкрементальна синхронізація**: запам'ятовувати позицію в стрічці, щоб щоденне оновлення займало секунди, а переможці й договори підтягувались без повного проходу за період.
- ⬜ Синхронізація стрічки договорів.
- ⬜ Пошук за регіоном і кодом CPV окремими параметрами (зараз лише через повнотекстовий пошук).
- ⬜ Конфіг «мої товари» з нашими цінами (потрібен для порівняння цін на етапі 3).

## Етап 3. Конкуренти та ціни ◐

**Результат за планом:** хто перемагає з товаром X, профіль конкурента, статистика цін перемоги, порівняння з нашими цінами.

- ✅ Сирі дані для аналізу в Excel: аркуші «Переможці» (сума, дата рішення, знижка, кількість учасників, договір), «Пропозиції», «Ціни за одиницю».
- ✅ Відбір за датою визначення переможця або підписання договору.
- ⬜ **«Що саме виграло»**: вендор, модель, кількість і ціна за одиницю з відповідей на критерії, товару Prozorro Market, договору та документів переможця (цінова й технічна пропозиція, листи авторизації). Результат: таблиця в базі й аркуш Excel. Потребує `read_document`. Почати з пілоту на 15–20 завершених тендерах з кібербезпеки.
- ⬜ `find_winners`: хто найчастіше перемагає за темою чи вендором і на яку суму.
- ⬜ `get_supplier`: профіль конкурента за ЄДРПОУ (де виграє, у яких замовників, середня знижка).
- ⬜ `get_winning_prices`: мінімальна, медіанна й максимальна ціна за одиницю за період.
- ⬜ `compare_with_my_prices`: порівняння з нашими цінами (потрібен конфіг «мої товари»).

## Виконано понад план ✅

Цього не було в початковому плані, але зроблено на запит:

- ✅ **Excel як основний формат результатів** (`export_excel`): аркуші «Тендери», «Позиції», «Переможці», «Пропозиції», «Ціни за одиницю»; посилання на prozorro.gov.ua, числові формати й дати, автофільтр; знижка рахується лише для порівнянних сум.
- ✅ **Завантаження тендерної документації** (`download_documents`): теки «Замовник - Предмет - UA-ID», документи пропозицій учасників (технічні та цінові пропозиції), оновлення тендера з API перед завантаженням, докачування лише нових і змінених файлів, захист шляхів і перевірка хостів.
- ✅ **Профілі фільтрів**: окремий профіль `cybersecurity` (активний за замовчуванням) і широкий `it-infrastructure`; активний профіль зберігається між сеансами; інший профіль можна застосувати до одного запиту; умови змінюються прямо в розмові (`list_filters`, `use_filter`, `save_filter`, `delete_filter`).
- ✅ **Теми в результатах**: групи ключових слів стають темами (`endpoint`, `siem_soc`, `identity`, `appsec_testing` тощо).
- ✅ **Виключення**: 71 код CPV (комплектуючі, кабелі, телефонія, прикладне ПЗ не за темою) і шаблони початку опису позиції (кабель, модуль пам'яті, жорсткий диск, блок живлення…), які діють за будь-якого коду.
- ✅ **Коди CPV для трьох напрямів** (`docs/cpv-codes.md`): кібербезпека, мережі, сервери і сховища; основні та загальні коди, ключові слова, виключення.
- ✅ **Специфікації API** (`api-specs/`): OpenAPI для Catalog, Risks і нової частини ЦБД, а також власний опис публічного API ЦБД для читання.
- ✅ **Командний рядок** (`prozorro-mcp sync | search | export | docs | filters`) для довгих операцій поза Claude Desktop.
